# Peitho Studioとは

- [mizzy](https://x.com/gosukenator)さん作のスライドツール [Peitho](https://peitho.gosu.ke/) をエンジンとしたアプリ
- Markdownでコンテンツを整え、HTMLのスライドができる
  - CSSは見た目
  - JavaScriptはふるまい
- ⇒ **HTMLスライドはいい**

# 設計の系譜

- Google Slides
  - 万人向けスライドツール。表現力豊かで、楽に使える
- [k1LoW/deck](https://github.com/k1LoW/deck)
  - Google Slidesの表現力とMarkdownによるコンテンツ管理を両立させる
- [mizzy/Peitho](https://github.com/mizzy/peitho)
  - k1LoW/deckの表現とコンテンツの分離設計は活かしつつ、表現手段をGoogle SlidesからHTMLに切り替え、よりAIフレンドリーに
- Peitho Studio
  - Peithoを楽に使えることを目指す
