2. 敵対的テスト(Adversarial testing)

  • 意図的に意地悪な値をいれる手法
    • (/code-review もそのエッセンスは入ってる)
  • 機械的な検証: 境界値カタログ
    • データ型ごとに「壊れやすい値」のカタログを用意
      • string → '', '<b>&"\'</b>', '😊' // 空、マーク、マルチバイト
      • number → 0, -7, Number.MAX_SAFE_INTEGER // ゼロ・負数・巨大値
      • array → 空配列
    • このカタログの値に自動差し替えするプログラムを書く
